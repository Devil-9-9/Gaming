# Zone Overdrive 3D
Unzip, open index.html in Chrome/Edge/Firefox (internet needed to load Three.js from a CDN).
Controls: WASD move, Shift sprint, Space jump, mouse aim, click shoot. Walk over items to pick up.
21 players (you + 20 bots), 3D map with trees and buildings, shrinking zone, 5 guns, loot, minimap, kill feed.
Next steps: building interiors, vehicles, squads, character models, multiplayer.
